# Security policy

## Supported versions

Security fixes are provided for the latest published minor release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, personal data, or access tokens.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within three business days.

## Disclosure

Please allow time for validation, remediation, regression testing, and coordinated release before public disclosure.
